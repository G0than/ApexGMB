# Local Map Pack Competitor Benchmark

Uncover why top competitors rank higher and exactly how to overtake them.

## What this skill does:
1. Compares target profile against the top 3 ranking competitors in the 3-Pack.
2. Identifies:
   - Primary category choices and secondary category overlap.
   - Review volume, rating discrepancy, and monthly review velocity.
   - Keyword presence in business titles (detects keyword stuffing vs clean branding).
   - Website domain authority & local landing page signals.
3. Produces a gap analysis matrix showing what changes will yield the highest rank improvements.

## Action Steps:
1. Open Google Maps using the MapRank Everywhere extension toolbar.
2. Inspect the top 3 competitors ranking for the target keyword.
3. Copy their categories and review stats.
4. Update the target profile with the missing secondary categories and increase photo/review cadence.
